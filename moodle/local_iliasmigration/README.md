# local_iliasmigration

Squelette du futur plugin local Moodle 4.5 utilisé par ILIAS2Moodle.

## État actuel

Le plugin n’effectue encore aucun import. Sa logique fonctionnelle commencera en **Phase 2 — Structure**.

L’objectif sera de créer les objets Moodle via les API Moodle et non par écritures SQL directes.
